# Server / Client Boundary

## RootLayout

Server Component

It provides shared application UI and metadata.

## MenuPage

Server Component

It reads dish data and renders the menu.

## DishPage

Server Component

It reads the route parameter and fetches the dish.

## Error

Client Component

It uses the reset function through a button.

## CartClient

Client Component

It manages interactive cart state.

## CheckoutPage

Server Component

It renders a form that invokes a Server Action.
